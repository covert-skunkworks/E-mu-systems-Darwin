E-mu Darwin emulator for Windows, Linux and macOS.

| Download | System |
|---|---|
| `Emu_Darwin-*-windows-x64.zip` | Windows 10 / 11, 64-bit: double-click `Emu_Darwin.exe` |
| `Emu_Darwin-*-linux-x64.tar.gz` | Linux x86-64: needs SDL2 and ALSA (`libsdl2-2.0-0`, `libasound2`) |
| `Emu_Darwin-*-macos-universal.zip` | macOS 11+, Apple Silicon and Intel: `Emu_Darwin.app` (not notarized: first run `xattr -dr com.apple.quarantine .` in the unpacked folder) |

**No firmware is included.** Put the ROM images of your own unit (`emu_darwin_v2_50.zip` or
`emu_darwin_v2_02.zip`) in the package's `Firmware` folder. Then click the E-MU logo for the
settings, make a disk on the Disks page, format it on the Darwin, and follow E-mu's original
owner's manual (available online, e.g. on archive.org). `README.txt` in each package has the
details.
